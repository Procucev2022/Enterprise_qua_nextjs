# Kiro Coding Assistant Instructions

## Unit Testing & Coverage Benchmark
- **Requirement**: Maintain **>= 90% Unit Test Code Coverage** per file across Statements, Branches, Functions, and Lines for all code in `app/` and `lib/`.
- **Command**: `npm run test:coverage`
- **Global Timeout**: 20,000ms.
- **Fail Check**: If any file has < 90% in any parameter, fail and fix before concluding.
